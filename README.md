# e-Sertipikat UIP3B Sumatera
Website prototype untuk "Rancang Bangun Sistem Informasi Pengolahan dan Monitoring Data e-Sertipikat Berbasis Web pada PT PLN (Persero) UIP3B Sumatera".

## Teknologi
- PHP 8+
- MySQL/MariaDB
- HTML5/CSS3
- Responsive dashboard

## Instalasi XAMPP
1. Salin folder `e-sertipikat-uip3b-sumatera` ke `C:/xampp/htdocs/`.
2. Jalankan Apache dan MySQL dari XAMPP.
3. Buka phpMyAdmin dan import `database/e_sertipikat.sql`.
4. Pastikan `config/database.php` sesuai username/password MySQL.
5. Buka `http://localhost/e-sertipikat-uip3b-sumatera/`.
